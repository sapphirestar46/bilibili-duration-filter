# B站动态 · 视频时长筛选

> 给 B 站动态页（`t.bilibili.com`）的「视频投稿」标签加一条**双滑块时长筛选条**，按视频时长区间过滤动态卡片。

B 站动态页把视频投稿、图文、专栏、追番混排在一起。想找「十分钟以上」或「半小时以内」的内容，只能一条条往下滑。这个脚本读取每条动态封面右下角已有的时长文本，用双滑块设定区间后直接把不匹配的卡片隐藏掉。

**纯前端实现**：只读取页面上已渲染的 DOM，不拦截请求、不改接口、不上传任何数据。停用脚本即可完全复原。

---

## 功能

| 功能 | 说明 |
| --- | --- |
| 双滑块时长区间 | 0 – 3 小时，两端分别是最短/最长时长，支持筛「10–30 分钟」这类区间 |
| 刻度偏向长视频 | 0–10 分钟占左侧 30%，10 分钟–3 小时占右侧 70%，筛长视频时拖动更精细 |
| 9 个预设 | 不限 / ≤1分钟 / 1–5 / 5–10 / 10–30 / 30–60 分钟 / ≥1小时 / **≥10分钟** / **≥30分钟** |
| 只在视频投稿生效 | 切到「全部 / 追番追剧 / 专栏」时筛选条整体隐藏，且不隐藏任何内容 |
| 吸顶自动收紧 | 向下滚动后压缩成只有滑条的窄条，不遮挡内容，也不会被 B 站页头挡住 |
| 实时计数 | 显示「显示 x / y」，无匹配时提示 |
| 自动加载更多 | 可见视频不足 20 条时自动补充，且不会把页面滚动位置拽走（仅视频投稿标签） |
| 时长未知不误伤 | 视频但没有时长（如转码中）时保留显示 |
| 状态记忆 | 区间、开关、选项都会保存，刷新后恢复 |

### 快捷键

| 操作 | 效果 |
| --- | --- |
| `Alt + Shift + D` | 启用 / 停用筛选 |
| `←` `→` | 焦点在滑块上时，步进 1 分钟 |
| `PageUp` `PageDown` | 步进 5 分钟 |
| `Home` / `End` | 跳到区间两端 |
| 双击滑块 | 单独重置该端 |

## 安装

### 方式一：GreasyFork（推荐）

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展。
2. **确保 Tampermonkey 已启用用户脚本权限**（新版 Chrome/Edge 必做一次）：
   - 打开 `chrome://extensions` → 找到 Tampermonkey → 「详细信息」→ 打开「允许用户脚本」。
   - 若没有该选项，按页面提示开启「开发者模式」。
3. 在本脚本的 GreasyFork 页面点击安装。

### 方式二：手动安装

1. 安装 Tampermonkey。
2. 点击扩展图标 →「添加新脚本」。
3. 把 [`bilibili-dynamic-duration-filter.user.js`](bilibili-dynamic-duration-filter.user.js) 的全部内容粘贴进去，`Ctrl+S` 保存。

## 使用

打开 <https://t.bilibili.com/>，**点击「视频投稿」标签**——筛选条会出现在标签栏正下方。

> 注意：脚本默认只在「视频投稿」标签显示。在「全部」标签下看不到筛选条是**预期行为**，因为那里混排了图文、专栏等内容，按时长筛选没有意义。

拖动左右两端滑块设定区间，例如：

- 只想看长视频 → 点 **「≥10分钟」**
- 只看 10–30 分钟 → 点 **「10–30分钟」**
- 排除一分内的短片 → 拖动左滑块到 1 分钟位置

筛选条的开关（最左侧复选框，或 `Alt+Shift+D`）用于临时停用；停用时整条变灰、滑块锁定，标题显示「（已停用）」。

## 已知限制

- **只支持 `t.bilibili.com`**。B 站首页、搜索页、分区页不适用。
- **B 站改版可能导致失效**。脚本依赖 `.bili-dyn-list__item`、`.duration-time` 等页面类名。若前端重构，典型表现是「计数正常但筛选不生效」。届时需要更新选择器。
- **统计范围是当前已渲染的动态**。被屏蔽、被折叠、尚未加载的动态不计入。
- **时长未知的视频不会被隐藏**（保守策略），所以在「只看短视频」时可能混入少量长视频。
